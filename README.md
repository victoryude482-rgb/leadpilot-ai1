# LeadPilot AI

Free-first B2B lead intelligence and sales workflow MVP.

## MVP

- Lead import (CSV/JSON)
- Business verification records
- Transparent 0–100 lead scoring
- Lead pipeline / CRM
- Personalized outreach drafts
- Dashboard metrics

## Product principle

LeadPilot distinguishes between **verified facts** and **predictions**. It never presents an estimated prospect score as a verified fact and does not automatically send outreach in the MVP.

## Planned architecture

The codebase is designed to keep lead providers, AI providers, messaging providers, and storage replaceable so the first deployment can use free-tier services.

## Status

MVP foundation is being built incrementally.
